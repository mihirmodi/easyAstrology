# easyAstrology - Release Notes

## v0.2 - Beta

- Added Remedy of the Day prediction.
- Added support for landscape mode.
- Bug fixes and improvements.

## v0.1 - Alpha

- Initial release.
- Daily horoscopes (Vedic and Western).
- Numerology predictions (life path number, lucky numbers, colours, gemstones).
- Profile dashboard with Sun Sign, Moon Sign, and Life Path Number.
- AI-powered daily predictions.
- Cross-platform Flutter app (Android, iOS, Web).
- Firebase authentication and data storage.
