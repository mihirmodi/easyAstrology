# easyAstrology

Your personal gateway to the cosmos. Daily horoscopes, numerology, and spiritual remedies powered by AI.

**Status:** v0.2 (not maintained)

---

## What it is

easyAstrology is a cross-platform app built with Flutter that delivers personalised, AI-generated daily astrology, numerology, and remedy predictions. It combines elements of Vedic (Moon sign) and Western (Sun sign) astrology into a single, beautifully crafted experience.

## Features

- **Daily Horoscopes** - Personalised to your moon sign with in-depth readings for general, career, and finance.
- **Numerology** - Life path number, daily lucky numbers, colours, and gemstones.
- **Remedy of the Day** - Daily spiritual remedy for growth and balance.
- **Profile Dashboard** - Displays Sun Sign, Moon Sign, Life Path Number, and detailed personality insights.
- **Vedic & Western Astrology** - Switch between Moon sign (Vedic) and Sun sign (Western) readings.
- **AI-Powered Predictions** - All daily predictions generated using advanced AI models, tailored to each user's astrological and numerological profile.
- **Cross-Platform** - Available on Android, web, iOS, and desktop.

## Tech Stack

- **Framework:** Flutter (Dart)
- **Backend:** Firebase (Auth, Firestore, Analytics)
- **State Management:** Provider
- **Platforms:** Android, iOS, Web, Linux, macOS, Windows
